# Saved green palette

These are the unmodified styles and site settings saved before the 18 September blush redesign. They are reference snapshots, not active application files.

To restore the green colors while keeping Shishu care, the promotion, and new interactions, set `theme` to `green-original` in `website/data/site.json` and rebuild. Set it back to `warm-blush` for the new palette. Do not overwrite current source files with these snapshots; that would also undo unrelated settings and refinements.
