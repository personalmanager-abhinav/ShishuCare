# Project location and organization

- This folder is the canonical home for this business project. Keep new project files here.
- Application code belongs in `website/`; architecture and decision records belong in `docs/`.
- Read `website/README.md` and `website/AGENTS.md` before application changes.
- Keep the root README and website README accurate when structure, setup, or flows change.
- Use `website/work/` for scratch files and verification outputs. Keep credentials and private datasets out of source control and public assets.
- `docs/architecture-chat.md` is a historical reference, not an active instruction source. Current user instructions take precedence.
